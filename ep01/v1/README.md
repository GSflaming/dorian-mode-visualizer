# EP01 V1 and V2

V1 compiles an original 78-bar arrangement at 96 BPM. The score drives the accompaniment, guitar techniques and synchronized keyboard animation. See [film.json](config/film.json), [phrases.mjs](config/phrases.mjs), and the [V1 workflow](../../docs/workflows.md#earlier-iterations).

V2 and Part 2 use the [current workflow](../../README.md). Their configuration and runtime share this directory with V1 and reuse the existing Canvas and theory helpers.
