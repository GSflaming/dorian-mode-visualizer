# Workflow reference

## V2 timeline and alignment

The starting album template in `ep01/v1/config/v2.json` uses placeholder filenames and source in-points. When studying a specific recording, retime the annotations to that edition. For your own recording start from `examples/local-audio.json`. The browser alignment tool saves to `config/v2.json`. It can also export the selected scene as JSON.

In the alignment view, use the track waveform to set the source in/out points. Use **H** for chords, **M** for bar markers, **B** for beats, and **Q/E** for subtitle start/end. Waveform transients and chroma changes are hints for listening and manual markup. A program timestamp is `scene.startMs + sourcePositionMs - audio.sourceInMs`. Scene and event intervals include their start and exclude their end. Changing the excerpt length shifts later scenes. See [the schema](../ep01/v1/config/v2.schema.json) for the available views and event shapes.

Preparation trims recordings on a 48 kHz sample grid, normalizes the excerpts and applies short boundary fades. The Node backend uses a centered Hann window and a 16,384-point FFT. It combines the stereo power spectra and maps interpolated peaks to pitch classes. Separate RMS and peak measurements follow the sample grid. The default installation is Node-only. If you already have Python with librosa, NumPy and SoundFile, `DORIAN_CHROMA=librosa npm run audio:prepare` requests the optional CQT backend. The manifest records the backend actually used.

```sh
npm run audio:prepare
npm run render -- --scene breathe
npm run render -- --snapshot-ms 1051.5 --theme dark
npm run render -- --layers waveform,chroma,reference,cues
```

V2 supports 30 and 60 fps. A scene render starts exactly at the scene’s program offset. It samples the stage at `scene.startMs + n * 1000 / fps` and trims the PCM to matching sample boundaries. FFmpeg may round the video stream up by less than a frame. Preview uses the media element’s playback time. Export checks configuration, asset, PCM and feature hashes before encoding.

For the original V2 A/B fixture, run `npm run verify` and open `http://127.0.0.1:4181/?mode=v2&demo=1` while the preview server runs. The matching alignment rehearsal is at `/?mode=align&demo=1`. Verification rebuilds that fixture.

## Eight-scene Part 2 with local material

The edition-specific branch in `ep01/v1/part2/lesson.mjs` and `recording-bars.json` uses 2023 stereo remaster anchors. It expects these FLAC basenames under `ep01/assets/audio/tracks/`.

- `breathe-2023.flac`
- `any-colour-2023.flac`
- `great-gig-2023.flac`

Keep recordings and performance data in your own local workspace with any necessary permissions. The Part 2 renderer also reads `ep01/v1/part2/evidence.json`, a local object with an `events` array. Supply your own authorized data. Each drawable event has an `excerptId` from the lesson configuration, a `part` such as `guitar` or `piano`, a sounding MIDI pitch in `midi`, and `startMs`/`endMs` on the source clock. Guitar events need one-based `string` (high E is 1) and `fret`. An optional `techniques` object supplies the guitar bend, vibrato or slide. The original voicings and TAB-derived event files stay in the production workspace. See [the synthetic study recipe](../examples/study-demo.mjs) for event examples generated entirely in code.

```sh
npm run part2:build --workspace ep01/v1 -- --prepare-only
npm run part2:preview --workspace ep01/v1
npm run part2:build --workspace ep01/v1
```

The last command also exports the 285-second, 60 fps film to `ep01/exports/EP01-part2.mp4`. Part 2 uses its own crossfades and normalizes at track level before recomputing features on the final master. The server binds to loopback. Rendered files can contain your local media and performance data, so keep the output directories private.

## Earlier iterations

**V0.1.** From the repo root, run `node ep01/scripts/serve.mjs` for the prototype. Run `node ep01/scripts/render.mjs --scene SC_04` for a single scene. Default audio is silence until WAV files described in [the recording notes](../ep01/assets/audio/README.md) are supplied. Native export for this version depends on Chrome/Chromium and FFmpeg. Set `CHROME_PATH` if the browser is not detected.

**V1.** From the repo root, install with `npm ci`. The score and MIDI are generated by `npm run score --workspace ep01/v1`. Generate the mix and FLAC stems with `npm run audio --workspace ep01/v1`. V1 looks for the system General MIDI DLS bank on macOS. Set `DORIAN_DLS` to a compatible local bank elsewhere. Render with `npm run render --workspace ep01/v1`, preview with `npm run preview --workspace ep01/v1`, and run `node ep01/v1/scripts/verify.mjs` after the full render.
